# zenith
An tailored Task Manager, meant to aid you in surpassing your self.

## Features
Task Management: Editable tasks which can be executed and timed accordingly

Cycle alarms: Cycle as the mininal, user-defined unit of work, once ended, the user is prompted a message (Custom, but, i.e. Strech, read) and is able to enter the InterCycle, an break period with defined amount to execute the prompt.
    - The alarm can be custom defined by the user specifying a path.


Upcoming:
    - Goal tracking: Tasks can have na associated Goal/Project 
    - Pillars of Life: Radar Chart with daily log format, for the sake of logging your actions across your own metrics.
    - AI integration: Highly optional, but if integrated, will integrate AI insights into some patterns you display accross usage
    - Desktop time tracker: An standalone app that tracks your usage across browser and window apps.
